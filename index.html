4 งาน

  • จองคิว Walk-in · Dashboard นัด/Walk-in เฉพาะชุดคลินิกของจุดออกบัตร แล้วออกบัตร V/P/N คนไข้ถือบัตรไปที่ช่องเวชระเบียน ซึ่งใช้หน้าเดิม: V เปิด Visit · P พิจารณา · N ลงทะเบียน HN ใหม่
  • ลงทะเบียนทำบัตร · หน้ากลางเลือกลงทะเบียน / ตรวจสอบ HN · คนไข้กรอกจากมือถือ แล้วห้องบัตรยืนยันเพื่อออก HN
  • เช็กอินออนไลน์ · ลิงก์ผ่านหมอพร้อม แบบสอบถามตามพระนั่งเกล้า (อาการปกติ/ผิดปกติ แพ้ยาใหม่ BP PR) เข้า Visit ตอนเปิด Visit นัด · หน้าคัดกรองมีธง
  • ขอนัดออนไลน์ · รับไม่จำกัด เลือกวัน จ.–อา. และช่วงวันที่ แล้วเจ้าหน้าที่ลงนัดในตารางเดิม

เคสในต้นแบบ

  • Counterบัตร V มี HN / ไม่มี HN · บัตร P · บัตร N · มีนัดแต่มาขอ Walk-in · เลือกชุดคลินิก · ไม่ได้นำบัตรมา (ค้นด้วย HN) · ตั้ง Limit ที่สรุปจุดบริการแล้ว Dashboard เปลี่ยนตาม
  • Onlineทำบัตรใหม่ (มีหน้ากลาง) · ตรวจสอบ HN · ทำบัตรซ้ำ · มีประวัติเก่าไม่มีเลขบัตร · ขอนัด (ผลดูในหมอพร้อม) · เช็กอินแจ้งอาการผิดปกติ · แจ้งเลื่อนนัด
  • ตู้ Kiosk เปิด Visit ได้เฉพาะนัดหมาย (ปิดทาง Walk-in) จึงไม่มีเคสแยก · ตอนเปิด Visit นัด API นำข้อมูลเช็กอินเข้า Visit ให้เอง

ที่ยังรออยู่

  • สเปก Limit ห้องตรวจต้องขึ้นใช้งานก่อนงานจองคิว Walk-in
  • IT เชื่อมการส่งลิงก์และแจ้งผลผ่านหมอพร้อม
  • ข้อความความยินยอม PDPA รอ DPO ของโรงพยาบาลตรวจ
