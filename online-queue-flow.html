Flow การใช้งานภาพรวม

ใครทำอะไร ที่จุดไหน และข้อมูลอะไรถูกส่งต่อไปที่ใคร แบ่งเป็น 5 งาน อ่านคู่กับแผน (ฉบับที่ 23) และต้นแบบที่กดได้ในโฟลเดอร์เดียวกัน

21 ต.ค. 2569ภาษาหน้างาน · รายละเอียดทางเทคนิคอยู่ในแผนและ Requirement

คนที่เกี่ยวข้อง

คนไข้หมอพร้อม (IT โรงพยาบาล)เวชระเบียนตู้ Kioskพยาบาลระบบ HA.OS
คนไข้มือถือ (แอป Mobile คิว) · หน้าโรงพยาบาล
  • ทำบัตร / ตรวจสอบ HN ออนไลน์
  • ขอนัด / แจ้งเลื่อนนัด
  • เช็กอินออนไลน์ก่อนวันนัด
  • Walk-in: รับบัตรคิวที่จุดออกบัตร
เจ้าหน้าที่จุดออกบัตรหน้าใหม่ "จองคิว Walk-in"
  • เสียบบัตรประชาชน ตรวจสิทธิ
  • เลือกคลินิกจาก Dashboard
  • ออกบัตรคิว V / P / N
ช่องเวชระเบียนหน้าทะเบียนประวัติ / เปิด Visit / นัด (หน้าเดิม)
  • บัตร V: เปิด Visit
  • บัตร P: พิจารณาเปิด Visit หรือนัด
  • บัตร N: ทำบัตรใหม่และนัด
ห้องบัตร / เจ้าหน้าที่นัดหมายเมนูใหม่ "คำขอทำบัตรออนไลน์" · "คำขอนัดออนไลน์"
  • ตรวจและยืนยันคำขอทำบัตร
  • ลงนัด / เลื่อนนัด / ปฏิเสธคำขอนัด
  • โทรแจ้งเมื่อส่งผลไม่ถึงหรือปฏิเสธ
ตู้ Kioskหน้าจอตู้เดิม
  • เปิด Visit ได้เฉพาะคนที่มีนัด
  • ไม่มีนัด: บอกให้ไปจุดออกบัตร
พยาบาลคัดกรอง / หัวหน้าพยาบาลหน้าเรียกคิวคัดแยก/ซักประวัติ · เมนูใหม่ "สรุปจุดบริการ"
  • ซักประวัติ เห็นข้อมูลเช็กอินและป้ายเตือน
  • เรียกคิวเข้าห้องตรวจ
  • ตั้งจำนวน Walk-in สูงสุดของแต่ละจุดบริการ
หมอพร้อม (IT โรงพยาบาล)ไลน์หมอพร้อม
  • ส่งผลทำบัตร
  • ส่งข้อความเตือนนัด + ลิงก์เช็กอิน
  • แสดงนัดของคนไข้
ระบบ HA.OSทำงานเบื้องหลัง
  • พักข้อมูลจากคนไข้ไว้จนเจ้าหน้าที่ยืนยัน
  • คำนวณที่ว่างจาก Limit และคิวห้องตรวจ
  • นำข้อมูลเช็กอินเข้า Visit ตอนเปิด Visit นัด

ภาพรวม 5 งาน

กดชื่องานเพื่อดูทีละขั้น

1. Walk-in รับบัตรคิว
คนไข้→จุดออกบัตร→ช่องเวชระเบียน→คัดกรอง→ห้องตรวจ
2. ทำบัตรออนไลน์
คนไข้→HA.OS พักคำขอ→ห้องบัตร→หมอพร้อม→คนไข้
3. ขอนัด / เลื่อนนัด
คนไข้→HA.OS พักคำขอ→เจ้าหน้าที่นัดหมาย→นัดขึ้นในหมอพร้อม
4. เช็กอินออนไลน์
หมอพร้อม เตือนนัด→คนไข้กรอก→เปิด Visit นัด (ตู้ / เคาน์เตอร์)→ข้อมูลเข้า Visit→คัดกรอง
5. ตั้งจำนวน Walk-in
หัวหน้าพยาบาล→HA.OS รวมยอด→Dashboard จุดออกบัตร

1. Walk-in รับบัตรคิว

หน้าโรงพยาบาล
1
คนไข้
มาที่จุดออกบัตรหน้าเวชระเบียน ยื่นบัตรประชาชนตู้ Kiosk ไม่รับ Walk-in แล้ว
ส่งบัตรประชาชน → เจ้าหน้าที่จุดออกบัตร
2
จุดออกบัตร
เสียบบัตร ระบบอ่านข้อมูลจากชิปและตรวจสิทธิหน้าจองคิว Walk-in · ไม่ได้นำบัตรมา: ค้นด้วย HN ได้ แต่ตรวจสิทธิไม่ได้
ได้ชื่อเลขบัตรวันเกิดที่อยู่ จากชิปบัตร
ได้สิทธิการรักษา จากระบบตรวจสิทธิเดิม
3
ระบบ HA.OS
เช็กว่ามี HN ไหม และมีนัดวันนี้ที่คลินิกเดียวกันไหมมีนัดวันนี้ = ไม่ออกบัตร Walk-in ให้ไปเปิด Visit นัด
ส่งHNนัดวันนี้ → หน้าจองคิว Walk-in
4
จุดออกบัตร
เลือกคลินิกจาก Dashboard ระบบเสนอประเภทบัตรV = ตรวจวันนี้ (ยังว่าง) · P = รอพิจารณา (เต็ม มี HN) · N = นัดวันอื่น (เต็ม ไม่มี HN)
ใช้ที่ว่าง = จำนวน Walk-in สูงสุด − ที่เรียกเข้าห้องตรวจแล้ว จากงานที่ 5 และคิวห้องตรวจ
5
จุดออกบัตร
พิมพ์บัตรคิว Walk-in ยื่นให้คนไข้พิมพ์อย่างเดียว ระบบไม่เก็บประวัติบัตร
ส่งบัตรคิว: ประเภท คลินิก ชื่อ HN สิทธิ เวลาที่ต้องยื่น → คนไข้ (กระดาษ)
6
ช่องเวชระเบียน
ดูบัตรคิว แล้วทำตามประเภท ด้วยหน้าจอเดิมV: เปิด Visit (ไม่มี HN ลงทะเบียนก่อน) · P: เปิด Visit หรือทำนัด · N: ทำบัตรใหม่และทำนัด
ได้Visitเลขคิวห้องตรวจ → พิมพ์บัตรคิวเดิมให้คนไข้
7
พยาบาลคัดกรอง
ซักประวัติ แล้วเรียกคิวเข้าห้องตรวจหน้าเรียกคิวคัดแยก/ซักประวัติ
ส่งเรียกเข้าห้องตรวจแล้ว 1 คน → Dashboard จุดออกบัตร (ที่ว่างลด)

ที่ว่างลดตอนเรียกเข้าห้องตรวจ ไม่ใช่ตอนออกบัตรหรือเปิด Visit ช่วงเช้าจึงอาจออกบัตร V เกินได้ (เรื่องที่ต้องตัดสินใจ G-32)

2. ทำบัตรออนไลน์

มือถือ → ห้องบัตร
1
คนไข้
สแกน QR หรือกดลิงก์บนเว็บโรงพยาบาล เจอหน้ากลาง เลือกตรวจสอบ HN หรือลงทะเบียนใหม่แอป Mobile คิว
ส่งเลขบัตร + วันเกิด → HA.OS (ตรวจสอบ HN)
ได้HN + ชื่อแบบปิดบางตัว ถ้าพบ แล้วไปขอนัดต่อได้
2
คนไข้
กรอกฟอร์มลงทะเบียน และติ๊กยินยอม PDPAผลจะแจ้งทางหมอพร้อม
ส่งข้อมูลส่วนตัวที่อยู่ผู้ติดต่อฉุกเฉินเวลาที่ยินยอม → HA.OS
3
ระบบ HA.OS
ตรวจเลขบัตรซ้ำ แล้วพักคำขอไว้ ยังไม่สร้างประวัติผู้ป่วยมี HN อยู่แล้ว: บอกแค่ "มีประวัติแล้ว"
ส่งเลขอ้างอิงคำขอ → คนไข้
ส่งคำขอทำบัตร → เมนูคำขอทำบัตรออนไลน์
4
ห้องบัตร
เปิดคำขอ ดูผลตรวจซ้ำ 2 ชั้น แก้ข้อมูลได้ แล้วเลือก สร้าง HN / ใช้ HN เดิม / ปฏิเสธเมนูคำขอทำบัตรออนไลน์ (หน้ารายการ → หน้ารายละเอียด)
ส่งข้อมูลผู้ป่วย → ทะเบียนผู้ป่วย HA.OS (เมื่อยืนยัน)
5
หมอพร้อม
ส่งผลให้คนไข้ตามเลขบัตรประชาชนส่งไม่ถึง: เจ้าหน้าที่โทรแจ้งตามเบอร์ที่กรอก
ส่งHN ใหม่ / HN เดิม / เหตุผลที่ปฏิเสธ → คนไข้
6
คนไข้
ครั้งแรกที่มาโรงพยาบาล นำบัตรประชาชนตัวจริงมายืนยันตัวตนที่ช่องเวชระเบียน
—

3. ขอนัด / เลื่อนนัด

มือถือ → เจ้าหน้าที่นัดหมาย
1
คนไข้
กรอกคำขอนัด หรือกดแจ้งเลื่อนนัดจากข้อความเตือนนัดยังไม่มี HN: พาไปทำบัตรก่อน
ส่งเลขบัตร + วันเกิดอาการคลินิกวันที่มาได้เบอร์รูปแนบ → HA.OS
2
ระบบ HA.OS
พักคำขอไว้ กันคำขอซ้ำ (เลขบัตร + คลินิกเดียวกัน)เลยวันสุดท้ายที่คนไข้เลือก = หมดอายุเอง
ส่งคำขอนัด / คำขอเลื่อนนัด → เมนูคำขอนัดออนไลน์
3
เจ้าหน้าที่นัดหมาย
กดลงนัด ระบบเปิดหน้านัดหมายเดิมพร้อมข้อมูลจากคำขอ หรือกดปฏิเสธพร้อมเหตุผลปฏิทินแพทย์มีวงบอกวันที่คนไข้มาได้
ส่งนัด → ตารางนัด HA.OS
4
หมอพร้อม
นัดที่ลงแล้วขึ้นในหมอพร้อมเอง ไม่มีหน้าแจ้งผลแยกเลื่อนนัด: ลิงก์เช็กอินของนัดเดิมใช้ไม่ได้
ส่งวัน เวลา คลินิก แพทย์ → คนไข้
5
เจ้าหน้าที่นัดหมาย
คำขอที่ปฏิเสธ โทรแจ้งคนไข้ใครเป็นคนโทร ยังต้องตัดสินใจ (G-37)
ส่งเหตุผลที่ปฏิเสธ → คนไข้ (โทรศัพท์)

4. เช็กอินออนไลน์

ก่อนวันนัด → วันนัด
1
ระบบ HA.OS
สร้างลิงก์เช็กอินประจำนัด ส่งให้ ITเลื่อน / ยกเลิกนัด = ลิงก์ใช้ไม่ได้
ส่งข้อมูลนัดลิงก์เช็กอิน → หมอพร้อม (IT)
2
หมอพร้อม
1 วันก่อนนัด ส่งข้อความเตือนนัด มีปุ่มเช็กอินออนไลน์ และแจ้งเลื่อนนัดเลขที่นัด เหตุผลการนัด ข้อควรปฏิบัติ
ส่งข้อความเตือนนัด + ลิงก์ → คนไข้
3
คนไข้
เลือกอาการปกติ / ผิดปกติ ตอบแบบสอบถาม แล้วกดยืนยันไม่สะดวกเดินทาง: มีปุ่มแจ้งเลื่อนนัด (งานที่ 3)
ส่งอาการวันนี้แพ้ยาใหม่ความดัน ชีพจรน้ำหนัก ส่วนสูง อุณหภูมิสูบบุหรี่ / สุรา → HA.OS (พักไว้ แก้ได้จนเปิด Visit)
4
ตู้ Kiosk / ช่องเวชระเบียน
วันนัด คนไข้เปิด Visit นัดตามปกติหน้าจอตู้และเคาน์เตอร์ไม่เปลี่ยน
ส่งเปิด Visit นัดแล้ว → HA.OS
5
ระบบ HA.OS
นำข้อมูลเช็กอินเข้า Visit ให้เองบันทึกไม่สำเร็จ ต้องไม่ทำให้เปิด Visit ล้ม
ส่งVital Signอาการสำคัญประวัติสูบบุหรี่ / สุราป้ายอาการผิดปกติ / แพ้ยาใหม่ → Visit
6
พยาบาลคัดกรอง
เห็นข้อมูลในช่องเดิมและป้ายเตือน วัดซ้ำได้ ยืนยันแพ้ยาใหม่ก่อนบันทึกหน้าเรียกคิวคัดแยก/ซักประวัติ (แก้เล็กน้อย)
ส่งแพ้ยาที่ยืนยันแล้ว → รายการแพ้ยา

อาการผิดปกติ: หน้าเช็กอินสำเร็จบอกให้คนไข้ติดต่อเคาน์เตอร์พยาบาลเมื่อมาถึง และแถวคิวขึ้นป้ายสีแดง

5. ตั้งจำนวน Walk-in สูงสุด

ตั้งครั้งเดียว ใช้ทุกวัน
1
หัวหน้าพยาบาล
ตั้งจำนวน Walk-in สูงสุดของแต่ละจุดบริการ เว้นว่าง = ไม่จำกัดเมนูใหม่ "สรุปจุดบริการ" · ระบบเก็บว่าใครแก้เมื่อไร
ส่งจำนวน Walk-in ต่อจุด → HA.OS
2
ระบบ HA.OS
รวมเฉพาะจุดที่มีแพทย์ออกตรวจวันนี้ เป็นยอดของคลินิกจำนวนนัดสูงสุดใช้ตามตารางแพทย์ (รอตัดสินใจ G-41)
ส่งจำนวน Walk-in ของคลินิกจำนวนนัดของคลินิก → Dashboard จุดออกบัตร
3
จุดออกบัตร
Dashboard ใช้ตัวเลขนี้คำนวณที่ว่าง และตัดสินบัตร V / P / Nแก้ตัวเลขแล้วมีผลกับบัตรที่ออกหลังจากนั้นทันที
ไปต่อที่งานที่ 1 ขั้นที่ 4

ข้อมูลที่วิ่งในระบบ

มาจากไหน ไปที่ไหน และระบบเก็บไว้หรือไม่

ข้อมูลมาจากไปที่เมื่อไรเก็บไว้ที่
ข้อมูลบัตรประชาชน (ชื่อ เลขบัตร วันเกิด ที่อยู่)ชิปบัตร ที่จุดออกบัตรหน้าจองคิว Walk-in · บัตรคิวเสียบบัตรไม่เก็บ ใช้พิมพ์บัตรเท่านั้น
สิทธิการรักษาระบบตรวจสิทธิเดิมหน้าจองคิว Walk-in · บัตรคิวเสียบบัตรไม่เก็บ · เวชระเบียนตรวจอีกครั้งตอนเปิด Visit
บัตรคิว Walk-in (V / P / N)จุดออกบัตรคนไข้ → ช่องเวชระเบียนออกบัตรกระดาษเท่านั้น
จำนวน Walk-in สูงสุดหัวหน้าพยาบาล (สรุปจุดบริการ)Dashboard จุดออกบัตรตั้งครั้งเดียวHA.OS (ตั้งค่าจุดบริการ)
จำนวนที่เรียกเข้าห้องตรวจแล้วคิวห้องตรวจDashboard จุดออกบัตรทุกครั้งที่เรียกคิวHA.OS (คิว)
คำขอทำบัตรคนไข้ห้องบัตรส่งฟอร์มที่พักคำขอ → ทะเบียนผู้ป่วยเมื่อยืนยัน
ผลทำบัตรHA.OSหมอพร้อม → คนไข้ห้องบัตรกดยืนยัน / ปฏิเสธสถานะการส่ง
คำขอนัด / คำขอเลื่อนนัดคนไข้เจ้าหน้าที่นัดหมายส่งฟอร์มที่พักคำขอ → ตารางนัดเมื่อลงนัด
นัดHA.OSหมอพร้อม → คนไข้ลงนัด / เลื่อนนัดตารางนัดเดิม
ข้อความเตือนนัด + ลิงก์เช็กอินHA.OSหมอพร้อม → คนไข้1 วันก่อนนัดลิงก์ประจำนัด
